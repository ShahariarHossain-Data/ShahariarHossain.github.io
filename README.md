# Shahariar Hossain Portfolio

**Live site:** [Open the portfolio](https://shahariarhossain-data.github.io/ShahariarHossain.github.io/)

Static portfolio website built with HTML, CSS, and JavaScript.

## Files

- `index.html` - portfolio page
- `profile.jpg` - profile photo used by the page

## Publish with GitHub Pages

In the repository settings, open **Pages** and select the `main` branch with the `/ (root)` folder as the publishing source. No build command or external dependencies are required.
